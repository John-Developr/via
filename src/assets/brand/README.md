# Brand source files

This folder contains canonical artwork used to generate native application
icons, launch assets, and other branded exports. These files are design sources,
not React Native runtime imports.

`tara-na.png` is the current application-icon source. Replace it with an opaque
1024×1024 or larger master when a higher-resolution export is available, then
regenerate the native icon sets in `ios/` and `android/`.
