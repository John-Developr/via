# Fonts

## Bricolage Grotesque

The app includes the Regular, Medium, SemiBold, Bold, and ExtraBold static
weights of Bricolage Grotesque. The font is licensed under the SIL Open Font
License 1.1; see `licenses/OFL-BricolageGrotesque.txt`.

Use the named `fontFamilies.bricolage` entries from the shared theme. Static
font names are intentional because they behave consistently across iOS and
Android without relying on synthesized weights.

## DM Sans

The app includes the Regular, Medium, SemiBold, and Bold static weights of DM
Sans for body copy, supporting text, labels, and buttons. It is licensed under
the SIL Open Font License 1.1; see `licenses/OFL-DMSans.txt`.

Use the named `fontFamilies.dmSans` entries from the shared theme.
